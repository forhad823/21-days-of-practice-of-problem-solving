# 🚀 21+ Days of Problem Solving with JavaScript (Progress Tracker)

This repository is my **personal progress tracker** for the **21 Days of Problem Solving with JavaScript** challenge, based on my instructor’s repository:

🔗 [Instructor's github repo](https://github.com/procodrr/21-days-of-problem-solving-with-js) \
🔗 [Youtube Playlist](https://www.youtube.com/playlist?list=PLfEr2kn3s-bp2nvjK7UMTCH-KTnPBFWq2)

The purpose of this repo is to **practice daily problem solving**, maintain **discipline**, and document **clear learnings** that will help me become a better JavaScript and software engineer.

---

## 🎯 Challenge Goal

- Build a **strong problem-solving mindset**
- Improve **JavaScript fundamentals** through daily practice
- Develop **algorithmic thinking** step by step
- Create a **public proof of consistency** on GitHub

---

## 🧭 Challenge Rules (Self‑Discipline)

- ✅ Solve problems **every day** (no skipping)
- ✅ Write **clean and readable JavaScript code**
- ✅ Add **short notes** explaining the logic
- ✅ Commit & push code **regularly**
- ❌ No copy‑paste without understanding

## 🧠 How I Solve Each Day

1. Read the problem from the instructor’s repo
2. Try to solve it **without looking at the solution**
3. Write clean JavaScript code
4. Test with multiple inputs
5. Write short notes explaining:

   - What I learned
   - Where I struggled
   - How I fixed it
